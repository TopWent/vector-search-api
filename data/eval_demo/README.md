# eval_demo

Tiny BEIR-format corpus for smoke-testing the evaluation pipeline.

- 20 corpus documents across four loose topics
- 5 queries
- 15 query-document relevance judgments with graded scores (1 = partial, 2 = direct)

This dataset is intentionally small. For real numbers use BEIR (SciFact, NFCorpus, FiQA) or MTEB.
